Superstore Sales Performance Dashboard (Power BI)
An interactive Power BI dashboard that analyzes Superstore sales, profit, customers, products, and regional performance from 2022 to 2024.
Project Overview
This project converts raw sales data into clear KPIs and visual insights. It helps a business team understand what is selling, where profit is coming from, and which areas need attention.
Objectives
Track overall sales, profit, and profit margin
Identify top-performing categories, products, and regions
Understand customer segments and order behavior
Provide business recommendations based on data
